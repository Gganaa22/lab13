# Self Evaluation

## 1. If the exam were today, could I write this code myself?

Partially.

I understand the main structure of the project and I can explain how the backend works. I know that the Express server receives HTTP requests and returns JSON responses. I also understand the main routes such as GET /tasks, POST /tasks, PUT /tasks/:id, and DELETE /tasks/:id.

However, I still need more practice to write the whole project quickly without help. I can write simple parts such as creating an Express server, adding routes, and returning JSON data. But I may need to check documentation or examples for testing with Jest and Supertest.

## 2. What would I do differently next time?

Next time, I would plan the commit history earlier and divide the work into smaller tasks from the beginning. I also would create the .gitignore file before installing Node packages, because I accidentally committed node_modules at first and had to remove it later.

I would also write tests earlier instead of adding them near the end. If tests are written earlier, it is easier to find bugs when adding new features.

## 3. What did I learn from this experience?

I learned how to use AI as an assistant, not as a replacement for my own understanding. AI helped me generate ideas, structure documents, and create draft code, but I still had to review, test, and fix the project myself.

I also learned the importance of Git workflow. Commit history shows how the project was developed step by step. Small commits are better than one large code dump.

Technically, I learned how to build a small Node.js and Express backend, create CRUD API endpoints, add search and filter features, write tests using Jest and Supertest, and organize project documentation.
